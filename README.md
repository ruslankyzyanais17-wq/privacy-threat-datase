# 🛡️ Датасет: Нарушение конфиденциальности (Задание №6)

Интерактивный дашборд и датасет для анализа, фильтрации и выгрузки примеров угроз приватности (**PRIVACY_THREAT**) в реальных переписках (на русском, казахском и английском языках).

---

## 📁 Структура репозитория

```text
privacy_threat_streamlit/
│
├── app.py                  # Главное приложение Streamlit
├── requirements.txt        # Список зависимостей (streamlit, pandas, altair)
├── run_app.bat             # Скрипт быстрого запуска для Windows (в один клик)
├── .gitignore              # Исключения для Git
├── README.md               # Документация и инструкция
└── data/
    ├── dataset.csv         # Полный датасет (48 записей, 9 классов, токены PII)
    └── dataset.jsonl       # Датасет в формате JSONL (для NLP / LLM)
```

## 🚀 Быстрый запуск на компьютере (локально)

### 1. Требования
* Установленный **Python 3.10+** (при установке обязательно включите галочку *"Add Python to PATH"*).

### 2. Запуск через скрипт (Windows)
Просто запустите файл:
```bash
run_app.bat
```

### 3. Либо запуск вручную через терминал:
```bash
# 1. Перейдите в папку проекта:
cd C:\Users\Lenovo\Desktop\privacy_threat_streamlit

# 2. Установите зависимости:
pip install -r requirements.txt

# 3. Запустите приложение:
streamlit run app.py
```
Приложение автоматически откроется в браузере по адресу: **http://localhost:8501**.

## 🌐 Как загрузить в Git и запустить через GitHub / Streamlit Cloud

Чтобы проект работал через Git и его можно было запустить в облаке Streamlit:

### Шаг 1: Создайте новый репозиторий на GitHub
1. Перейдите на [GitHub](https://github.com/new).
2. Назовите репозиторий, например: `privacy-threat-dataset`.
3. Оставьте его **Public** (или Private) и нажмите **Create repository**.

### Шаг 2: Отправьте проект в Git
Откройте терминал (PowerShell или Git Bash) в папке `privacy_threat_streamlit`:
```bash
cd C:\Users\Lenovo\Desktop\privacy_threat_streamlit

# Инициализация репозитория
git init
git branch -M main

# Добавление всех файлов
git add .
git commit -m "Initial commit: Streamlit dataset app for Privacy Threat"

# Привязка вашего GitHub (замените URL на ссылку вашего репозитория):
git remote add origin https://github.com/<ВАШ_ЛОГИН>/privacy-threat-dataset.git
git push -u origin main
```

### Шаг 3: Развёртывание на Streamlit Community Cloud (бесплатно)
1. Перейдите на [share.streamlit.io](https://share.streamlit.io/).
2. Авторизуйтесь через свой GitHub-аккаунт.
3. Нажмите кнопку **"New app"**.
4. Выберите:
   * **Repository:** `<ВАШ_ЛОГИН>/privacy-threat-dataset`
   * **Branch:** `main`
   * **Main file path:** `app.py`
5. Нажмите **"Deploy!"**.
6. Через 1–2 минуты ваше приложение получит постоянную публичную ссылку вида:
   `https://privacy-threat-dataset-...streamlit.app`!

## 📊 Классификация данных (9 подклассов по ТЗ)

1. **DOXING** — дербес деректерді жария ету / публикация персональных данных;
2. **DOXING_THREAT** — мәліметтерді жариялаймын деп бопсалау / угроза публикации данных и шантаж;
3. **PHONE_DISCLOSURE** — телефон нөмірін тарату / несанкционированная публикация номера телефона;
4. **ADDRESS_DISCLOSURE** — тұрғылықты мекенжайды жариялау / публикация адреса проживания;
5. **LOCATION_DISCLOSURE** — нақты орналасқан жерін ашу / раскрытие текущей геолокации;
6. **IDENTITY_DISCLOSURE** — жасырын пайдаланушының жеке басын ашу (деанонимизация);
7. **PRIVATE_MESSAGE_LEAK** — жеке хат алмасуды жария ету / публикация закрытой переписки;
8. **INTIMATE_CONTENT_LEAK** — интимдік материалдарды тарату / распространение интимных фото/видео;
9. **PERSONAL_DATA_REQUEST** — дербес деректерді заңсыз іздеу («пробив» по базам данных).

### Стандарты анонимизации (100% защита ПДн)
Все личные данные заменены стандартизированными токенами:
* `[ИМЯ]` — ФИО, псевдонимы реальных людей;
* `[ТЕЛЕФОН]` — мобильные номера;
* `[АДРЕС]` — улицы, номера домов, квартиры;
* `[EMAIL]` — адреса электронной почты;
* `[АККАУНТ]` — никнеймы в соцсетях;
* `[ГЕОЛОКАЦИЯ]` — координаты, названия конкретных заведений.
